# AI skill for sony-bravia-linux

Operating rules for working on this project with AI assistance.

| File | What it is |
|---|---|
| `SKILL.md` | The rules. Two halves: what the project requires, then how to actually meet it. |

It is plain Markdown on purpose, so it is not tied to any one assistant:

- **Claude Code or Claude.ai:** `SKILL.md` carries the usual frontmatter, so drop this folder into your skills directory and it loads as `sony-bravia-linux-contributing`.
- **ChatGPT or similar:** paste `SKILL.md` into a custom instruction or project.
- **Anything else, including a local model:** paste it at the top of the conversation.
- **No assistant at all:** it works as a human checklist.

Daniel's position on AI assistance is in [PROVENANCE.md](../PROVENANCE.md#on-slop). The sibling skill for the Consumer Rights Wiki is [crwiki-ai-skill](../crwiki-ai-skill/).
