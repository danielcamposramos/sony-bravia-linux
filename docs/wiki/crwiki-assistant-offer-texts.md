# The two short texts that go with the instructions file

Both are drafts for the owner to adjust and send. The instructions themselves are in
`crwiki-assistant-instructions.md`.

## For the Discord suggestions channel (short, fits the free limit)

Following the AI usage policy discussion: I put together a set of operating
instructions for an AI assistant editing here. It is plain Markdown, not tied to any
product, so it works pasted into whatever assistant someone already uses.

The policy says providing it as context "does not ensure that the output will be
fitting", and that is the gap this tries to fill: it turns the rules into things a
model has to do rather than things it has been told.

Every item is something I got wrong on this wiki first. Three citation templates
broken across lines that a reviewer had to fix by hand, a model "confirming" a
quotation while quoting different words back at me, and a Sony support page I nearly
cited as listing 367 affected models when it was a search box.

Offered, not proposed: <LINK>

Happy to send it as a file, or to see it live on-wiki if anyone wants it there. Your
call entirely on all three.

## For the talk page, as a further reply

I have written up the operating side of this as a separate document, in case it is
useful: <LINK>

It is deliberately not a policy proposal and not tied to any one assistant. It is the
set of rules that make a model behave on this wiki, as opposed to the policy, which
tells it what is wanted. The distinction matters because the policy already says that
giving a model the policy "does not ensure that the output will be fitting", and I
think that is exactly right.

Every rule in it is something I did wrong here first, which is also why it is offered
rather than proposed. If it is useful, someone is welcome to move it on-wiki and
maintain it properly; if it is wrong in places, I would rather hear that than have it
quietly ignored. The people best placed to correct it are the ones who have reverted
an AI edit and know which rule was missing.
