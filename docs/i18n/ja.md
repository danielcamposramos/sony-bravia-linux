# ソニー ブラビア 3Dテレビ（2011〜2012年モデル）で3D映像・3D写真をもう一度：オーナーが運用するオープンソースの修理プロジェクト

<!-- lang: ja · canonical source: ../../README.md (English) · translated 2026-09-18 -->

ソニーがネットサービスを終了した、Android以前のブラビア（KDLシリーズ、2010〜2012年）を、オーナー自身の家庭内ネットワークで復活させるプロジェクトです。ファームウェアは一切改変せず、DRM（著作権保護）にも触れません。**修理する権利（Right to Repair）**の実践です。

## こんな疑問で検索しましたか？

このページは、次のような疑問に答えます：

- 「3DSで撮った3D写真をブラビアで見たいが、うまくいかない」
- 「ブラビアで3D写真が3Dで見れない」
- 「USBメモリの3D写真を認識しない」
- 「サイドバイサイドの動画をUSBで再生しても3Dにならない」
- 「3Dメニューに左右分割方式が出てこない」
- 「ホームネットワークの3D動画が3D表示できない」
## 3D動画を再生しても立体にならない理由

- このテレビが**自動で3Dに切り替わる**のは、**映像ストリーム自体**にH.264の「フレームパッキング」情報（SEI）が入っているときだけです。
- 一般的な3Dファイル（MKVのサイドバイサイド／トップアンドボトム）はコンテナ側のタグしか持っておらず、DLNAサーバー経由で配信されるとそのタグは失われます。結果、画面は左右に並んだまま、3Dになりません。
- **解決策（無劣化・再エンコード不要）**：`tools/bravia_sei3d.py` でファイルにSEIを一度書き込むだけで、以後はDLNA経由でもテレビが自動で3Dに切り替わります。HandBrakeにもこの機能が取り込まれました（PR #8100、次のリリース）。付属のServiioプロファイルは、トランスコード時にSEIを自動で付加します。
- 左右の目が逆になる？ テレビ側では左右を入れ替えられませんが、ffmpegのフィルター（`stereo3d=sbsl:sbsr`）なら可能です。

## 3D写真（サイドバイサイド／JPS／MPO）

- 実測（KDL-46EX725・KDL-46HX855）：DLNAやUSBの写真表示で3Dボタンを押しても、出てくるのは**「2D→3D変換」だけ**で、写真用のサイドバイサイドの選択肢はありません。
- ニンテンドー3DSや3Dカメラで撮った**3D写真**（ファイル形式はMPO）をUSBメモリーから再生する方法は、ソニーの2011年モデル対応表に記載があります。一方、2010年モデル（KDL-46HX800）では3DSの3D写真がUSB経由で3Dにならなかったという報告もあり、現在、カメラと同じフォルダー構成（DCIM）で検証中です。
- アナグリフ（赤青メガネ）の写真・動画はサイドバイサイドに変換できます：`tools/bravia_anaglyph.py`。

## 対象機種

- 検証済み：**KDL-46EX725**（2011年）、**KDL-46HX855**（2012年）
- 同じボード系列：KDL-46EX724、KDL-40HX853、KDL-55HX753
- 日本国内の同世代3D対応モデルは未検証ですが、同じ世代のため当てはまる可能性があります。
- 3D信号（SEI）の問題は、ストリームから3Dを自動判別するテレビやプロジェクター全般に関係します（サムスン製でも同じ症状の報告があります）。
