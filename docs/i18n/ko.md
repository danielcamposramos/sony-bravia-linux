# 소니 브라비아 3D TV(2011–2012년 모델)에서 3D 영상과 3D 사진 다시 보기: 소유자가 직접 운영하는 오픈소스 수리 프로젝트

<!-- lang: ko · canonical source: ../../README.md (English) · translated 2026-09-18 -->

소니가 온라인 서비스를 종료한 안드로이드 이전 브라비아(KDL 시리즈, 2010–2012년)를 소유자 자신의 홈 네트워크에서 되살리는 프로젝트입니다. 펌웨어는 전혀 수정하지 않으며 DRM(저작권 보호)도 건드리지 않습니다. **수리할 권리(Right to Repair)**의 실천입니다.

## 이런 질문으로 검색하셨나요?

이 페이지는 다음과 같은 질문에 답합니다:

- "브라비아 3D 사진 USB로 보면 인식 안됨"
- "사이드바이사이드 영상 USB 재생하면 3D로 안 바뀜"
- "3D 메뉴에 좌우 분할이 안 뜸"
- "3D는 HDMI로만 되나요?"
- "브라비아에서 3D 사진 보는 방법"
## 3D 영상을 재생해도 입체로 보이지 않는 이유

- 이 TV는 **영상 스트림 자체**에 H.264 '프레임 패킹'(frame packing) SEI 정보가 있을 때만 **자동으로 3D로 전환**됩니다.
- 일반적인 3D 파일(MKV 사이드바이사이드/탑앤바텀)은 컨테이너 태그만 가지고 있어, DLNA 서버를 거치면 이 태그가 사라집니다. 그 결과 화면이 좌우로 나뉜 채 3D로 바뀌지 않습니다.
- **해결 방법(무손실, 재인코딩 불필요)**: `tools/bravia_sei3d.py`로 파일에 SEI를 한 번만 기록하면, 이후 DLNA로 재생할 때 TV가 자동으로 3D로 전환합니다. HandBrake에도 이 기능이 반영되었습니다(PR #8100, 다음 릴리스). 함께 제공되는 Serviio 프로필은 트랜스코딩할 때 SEI를 자동으로 추가합니다.
- 좌우 눈이 바뀌었나요? TV에서는 좌우를 바꿀 수 없지만 ffmpeg 필터로는 가능합니다(`stereo3d=sbsl:sbsr`).

## 3D 사진(사이드바이사이드 / JPS / MPO)

- 실측(KDL-46EX725, KDL-46HX855): DLNA나 USB 사진 보기에서 3D 버튼을 누르면 **'2D→3D 변환'만** 나오고, 사진용 사이드바이사이드 옵션은 없습니다.
- 3D 카메라의 표준 형식인 **MPO**를 USB 메모리에서 재생하는 방법은 소니 2011년 모델 호환표에 나와 있고 소유자들의 보고도 있습니다. 현재 검증 중입니다.
- 애너글리프(적청 안경) 사진과 영상은 사이드바이사이드로 변환할 수 있습니다: `tools/bravia_anaglyph.py`.

## 대상 모델

- 검증 완료: **KDL-46EX725**(2011), **KDL-46HX855**(2012)
- 같은 보드 계열: KDL-46EX724, KDL-40HX853, KDL-55HX753
- 3D 신호(SEI) 문제는 스트림에서 3D를 자동 판별하는 모든 TV와 프로젝터에 해당합니다(삼성에서도 같은 증상이 보고되었습니다).
