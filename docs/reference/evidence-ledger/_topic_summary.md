# Signal Ledger reference

The Signal Ledger is the claim-boundary layer for the repository. Start with
[`claims.md`](claims.md), the generated view of the canonical TOML registry.

It exists to stop three common forms of drift:

- a register or log line being retold as physical display behavior;
- a local hardware limitation being generalized into a global result;
- a corrected diagnosis continuing to authorize downstream conclusions.

The pilot covers the paired nouveau/NVIDIA HDMI Deep Color result. It names
Daniel as the physical observer, keeps HDR and 16-bpc explicitly untested, and
binds every run log by SHA-256. Tool and schema details are in
[`tools/evidence-ledger/ledger.py.md`](../../../tools/evidence-ledger/ledger.py.md).
