@Karppila one angle nobody has covered yet: how a Sony ages once the software support ends. I still run a KDL-46EX725 (2011) and a KDL-46HX855 (2012), both 3D sets, so here is the long-term view.

@BillBill is right about the hardware: the panels still look great after all these years.
The software did not last. Sony switched the services off one by one (Facebook, Skype, SideView, TrackID, Twitter, each with its own dated notice, which I archived), and the source code it once published for these Linux-based sets is no longer listed for this generation.

@yock1 your "wait for the next firmware update" story is the same pattern from the other end: on my sets the updates simply stopped.

@johnt's advice is the realistic plan with either brand, and it is what I ended up doing: the sets are off Sony's servers and run my own media portal on the LAN, on free software, and both play my whole library again, 3D movies included.

So for a buyer today: pick the panel you prefer, and assume the smart platform has an expiry date. Underneath both it is Linux, which is what made mine fixable.
